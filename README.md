# THEORY

Prompt Engineering is the process of designing and refining prompts to guide Artificial Intelligence models toward producing accurate, meaningful, and context-aware responses.

Different prompting methods influence how effectively an AI model understands and performs a task.

## Prompting Techniques Used

| Technique | Description |
|------------|-------------|
| Basic Prompt | Simple and direct instruction with minimal context |
| Zero-Shot Prompting | AI performs the task without examples |
| Few-Shot Prompting | AI is guided using sample examples |
| Chain-of-Thought Prompting | AI reasons step-by-step before generating the final answer |

# SCENARIO 3 — CODING ASSISTANCE

## TASK

Generate a Python program to check whether a number is prime.

---

# ACTIVITY 1 — BASIC PROMPT

## Prompt

```text
Write a Python program to check prime number.
```

## Response

```python
n = int(input())

count = 0

for i in range(1, n+1):
    if n % i == 0:
        count += 1

if count == 2:
    print("Prime")
else:
    print("Not Prime")
```

---

# ACTIVITY 2 — ZERO-SHOT PROMPTING

## Prompt

```text
Write a Python program to check whether a number is prime.
Use proper variable names and comments.
```

## Response

```python
number = int(input("Enter a number: "))

is_prime = True

if number <= 1:
    is_prime = False
else:
    for i in range(2, number):
        if number % i == 0:
            is_prime = False
            break

if is_prime:
    print("Prime Number")
else:
    print("Not a Prime Number")
```

# FINAL OBSERVATION

From the comparative analysis, it is clear that the quality of AI-generated responses improves significantly as prompts become more structured and detailed.

- Basic prompts generated short and generic outputs.
- Zero-shot prompts improved clarity and relevance.
- Few-shot prompting enhanced consistency by guiding the model with examples.
- Chain-of-Thought prompting produced the most detailed, logical, and accurate responses because the model reasoned through the task before generating the final answer.

Among all techniques, Chain-of-Thought prompting consistently delivered the best performance across creative writing, educational explanation, and coding scenarios.



# RESULT

The experiment was successfully conducted to compare different prompting techniques in Large Language Models.

From the analysis, it was observed that:

- Basic prompts produced generic responses with limited depth.
- Zero-shot prompting improved clarity and relevance.
- Few-shot prompting enhanced consistency and formatting.
- Chain-of-Thought prompting generated the best responses in terms of reasoning, quality, and completeness.

Therefore, prompt engineering plays an important role in improving the effectiveness and reliability of AI-generated outputs.
